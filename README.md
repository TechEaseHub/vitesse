## 项目介绍

本项目基于 Vitesse 模板，进行了定制配置和二次开发，适合作为快速启动 Vue 3 + Vite 的轻量级脚手架。
保留了原模板的核心特性，同时根据实际需求做了调整和优化，方便后续项目迭代。

---

## 特性

- ⚡️ 基于 [Vue 3](https://github.com/vuejs/core)、[Vite](https://github.com/vitejs/vite)、[pnpm](https://pnpm.io/) 和 [ESBuild](https://github.com/evanw/esbuild)，启动快速
- 🗂 文件路由，基于文件结构自动生成路由
- 📦 组件自动导入，免去手动引入烦恼
- 🎨 使用 [UnoCSS](https://github.com/antfu/unocss) 作为即时按需原子化 CSS 引擎
- 😃 支持多种图标集，通过 Pure CSS 方式轻松使用图标
- 🔥 采用 Vue `<script setup>` 语法糖，简洁高效
- ✅ 集成 [Vitest](http://vitest.dev/) 单元及组件测试支持
- 🦾 完全 TypeScript 支持
- ☁️ 可无配置部署到 Netlify 等平台

---

## 预装依赖

- [`unocss`](https://github.com/antfu/unocss) — 即时按需原子化 CSS 引擎
- [`unplugin-icons`](https://github.com/unplugin/unplugin-icons) — 支持多种图标集
- [`vue-router`](https://github.com/vuejs/vue-router) + [`unplugin-vue-router`](https://github.com/posva/unplugin-vue-router) 实现文件路由
- [`vite-plugin-vue-layouts`](https://github.com/JohnCampionJr/vite-plugin-vue-layouts) 实现路由布局
- [`unplugin-auto-import`](https://github.com/antfu/unplugin-auto-import) 自动导入 Vue Composition API 等
- [`unplugin-vue-components`](https://github.com/antfu/unplugin-vue-components) 组件自动导入
- [`vueuse`](https://github.com/antfu/vueuse) 丰富的组合式 API 集合
